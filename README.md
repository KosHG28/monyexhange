# Курс по чеку

Калькулятор для путешественников: сколько на самом деле стоит покупка за границей в вашей валюте,
если платить своей картой. Курс считается по вашим банковским чекам — пополнение карты и покупки по ней —
и сверяется с официальным курсом ЦБ РФ. Главная функция — камера: наводишь на ценник, и поверх
каждой цены прямо в видоискателе появляется сумма в вашей валюте.

Раньше приложение называлось «Дирхамы в рубли» и умело только дирхамы и две карты; обновление
ставится поверх и переносит карты и чеки.

## Установка на Android

1. Откройте на телефоне страницу **[Releases](../../releases/latest)** этого репозитория.
2. В разделе **Assets** нажмите на файл `dirhamrub-vX.Y.Z.apk` — он скачается.
3. Откройте скачанный файл (из шторки уведомлений или из «Загрузок»).
4. Android попросит разрешить установку из этого источника: **Настройки → Разрешить из этого источника**
   (браузеру или файловому менеджеру), затем вернитесь назад и нажмите **Установить**.
5. Если Google Play Protect предупредит о неизвестном приложении — нажмите **Всё равно установить**:
   приложение личное и не опубликовано в Google Play.

Нужен Android 8.0 или новее. Интернет нужен только для курсов ЦБ.

**Обновление.** Все версии подписаны одним и тем же ключом, поэтому новую версию из Releases
просто устанавливайте поверх старой — курсы, чеки и последняя сумма сохранятся.

## Что умеет

- **Свои карты** в любой валюте (₽, AED, ₺, ฿, $, €, ¥, ₸, ₾, ֏, ₫, Br, сум, сом). Для каждой — чек пополнения
  («отправил 15 000 ₽ → пришло 80 900 ₸») и чеки покупок в разных валютах («списали 2 757,48 ₸ за 22 AED»).
  Курс карты = валюта карты за единицу трат × ваша валюта за единицу карты. Нет чека покупки в нужной валюте —
  курс ЦБ с наценкой этой карты, посчитанной по её другим чекам. Можно задать курс вручную.
- **Сверка с ЦБ РФ**: на каждой карте видно, на сколько она дороже или дешевле официального курса
  («+4,7 % к ЦБ»), лучшая карта отмечена. Курсы ЦБ скачиваются раз в несколько часов и работают офлайн.
- **10 валют трат**: дирхам ОАЭ, турецкая лира, тайский бат, доллар, евро, юань, тенге, лари, драм, донг.
  Итог — в любой валюте на выбор (по умолчанию рубли).
- **Главный экран**: карты с ценой текущей покупки и наценкой к ЦБ, крупная сумма и подсказка, какой картой
  дешевле платить (свайп по сумме — другая карта), курс ЦБ с датой, поле ввода с переключателем «AED | ₽ | ¥» (вводить
  в итоговой или в валюте карты), «Спишется с карты», быстрые суммы, своя клавиатура с «+» и «×»
  («3 × 22 + 15»).
- **Чек из скриншота банка**: в редакторе карты — «Заполнить из скриншота», суммы чека пополнения
  или покупки распознаются на телефоне, без интернета.
- **Подсказка валюты по стране**: прилетели в Казахстан — приложение предложит считать в тенге
  (страна берётся из сотовой сети, без интернета).
- **Знакомство при первом запуске**: где тратите, в чём считать итог, как добавить карту.
- **Курс ЦБ с изменением за неделю**: «ЦБ: 1 AED = 21,97 ₽ ↑0,4 % · 30 окт».
- **Шпаргалка** — типичные суммы по каждой карте и по ЦБ.
- **Камера «Ценник»:** сумма в рублях (или в итоговой валюте) вписывается прямо в ценник вместо старой
  цены — цветом его бумаги и цифр; удержание пальца показывает оригинал, переключатель «Плашки» —
  метки над ценами. Цена у прицела —
  в фокусе, подробности в карточке внизу; тап по метке —
  подробности по всем картам и «+ к сумме», фонарик, пауза, пинч-зум, фокус по тапу.

## Ограничения версии 0.1

- **Арабские цифры** (٠١٢٣٤٥٦٧٨٩) распознаватель ML Kit (латиница) не читает. Цены на ценниках
  в ОАЭ почти всегда продублированы обычными цифрами — их и находит камера.
- **Зачёркнутую цену** распознаватель не видит как зачёркнутую. Старой считается цена рядом со словом
  WAS / OLD / RRP или мелкая цена рядом с крупной новой, если она больше; такие метки серые и перечёркнуты.
- Метки рисуются только для цен в диапазоне 0,5–100 000 AED; телефоны, штрихкоды, даты, время,
  проценты, объёмы и веса отбрасываются.

## Сборка

```bash
./gradlew testDebugUnitTest lintDebug assembleDebug     # тесты, lint и debug APK
./gradlew assembleRelease                                # release APK (R8), тот же ключ
./gradlew -p tools/domain-check test                     # тесты domain-кода без Android SDK
```

Нужны JDK 17+ и Android SDK (compileSdk 37). CI (`.github/workflows/android.yml`) на каждый push
гоняет тесты, lint и собирает оба APK; на тег `v*` публикует GitHub Release с APK.
Подробности для разработки — в [CLAUDE.md](CLAUDE.md), требования — в [docs/SPEC.md](docs/SPEC.md),
принятые решения — в [docs/DECISIONS.md](docs/DECISIONS.md).
