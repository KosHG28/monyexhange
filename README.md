# Дирхамы в рубли

Личный калькулятор для поездки в ОАЭ: переводит цены в дирхамах (AED) в рубли по курсу,
посчитанному из своих банковских чеков, для двух карт — в тенге (₸) и в юанях (¥).
Главная функция — камера: наводишь на ценник, и поверх каждой цены прямо в видоискателе
появляется сумма в рублях.

Работает без интернета: курс считается из чеков, текст на ценниках распознаётся на телефоне.

## Установка на Android

1. Откройте на телефоне страницу **[Releases](../../releases/latest)** этого репозитория.
2. В разделе **Assets** нажмите на файл `dirhamrub-vX.Y.Z.apk` — он скачается.
3. Откройте скачанный файл (из шторки уведомлений или из «Загрузок»).
4. Android попросит разрешить установку из этого источника: **Настройки → Разрешить из этого источника**
   (браузеру или файловому менеджеру), затем вернитесь назад и нажмите **Установить**.
5. Если Google Play Protect предупредит о неизвестном приложении — нажмите **Всё равно установить**:
   приложение личное и не опубликовано в Google Play.

Нужен Android 8.0 или новее.

**Обновление.** Все версии подписаны одним и тем же ключом, поэтому новую версию из Releases
просто устанавливайте поверх старой — курсы, чеки и последняя сумма сохранятся.

## Что умеет

- **Курс из чеков.** Для каждой карты два чека: перевод (отправил ₽ → пришло ₸/¥) и покупка
  (списали ₸/¥ за AED). Из них: `rubPerAed = (cardPaid / aedPaid) / (cardGot / rubSent)`.
  Курс можно задать и вручную. Стартовые чеки от 29 октября 2026: 1 AED ≈ 23,2398 ₽ по тенге
  и ≈ 22,4467 ₽ по юаням.
- **Главный экран:** две мини-карты (выгодная помечена «дешевле на 3,4 %»), крупная сумма в рублях,
  сравнение карт на текущей сумме, «линия метро» AED / ₽ / валюта карты — ввод в любую строку,
  быстрые суммы, своя клавиатура с «+» для суммы нескольких покупок.
- **Шторка «Курс»** — тап по плашке «1 AED = … ₽ ✎»: ручной курс и бумажный чек, итог считается на лету.
- **Шпаргалка** — 1…1000 AED в рублях по обеим картам.
- **Камера «Ценник»:** рубли поверх цен в реальном времени, тап по метке — подробности и «+ к сумме»,
  переключатель карты ₸/¥, фонарик, пауза (заморозить кадр), пинч-зум, фокус по тапу.

## Ограничения версии 0.1

- **Арабские цифры** (٠١٢٣٤٥٦٧٨٩) распознаватель ML Kit (латиница) не читает. Цены на ценниках
  в ОАЭ почти всегда продублированы обычными цифрами — их и находит камера.
- **Зачёркнутую цену** распознаватель не видит как зачёркнутую. Старой считается цена рядом со словом
  WAS / OLD / RRP или мелкая цена рядом с крупной новой, если она больше; такие метки серые и перечёркнуты.
- Метки рисуются только для цен в диапазоне 0,5–100 000 AED; телефоны, штрихкоды, даты, время,
  проценты, объёмы и веса отбрасываются.

## Сборка

```bash
./gradlew testDebugUnitTest lintDebug assembleDebug     # тесты, lint и debug APK
./gradlew assembleRelease                                # release APK (R8), тот же ключ
./gradlew -p tools/domain-check test                     # тесты domain-кода без Android SDK
```

Нужны JDK 17+ и Android SDK (compileSdk 37). CI (`.github/workflows/android.yml`) на каждый push
гоняет тесты, lint и собирает оба APK; на тег `v*` публикует GitHub Release с APK.
Подробности для разработки — в [CLAUDE.md](CLAUDE.md), требования — в [docs/SPEC.md](docs/SPEC.md),
принятые решения — в [docs/DECISIONS.md](docs/DECISIONS.md).
