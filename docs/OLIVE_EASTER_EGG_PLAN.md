# «Время оливок»: доработка 1.43.0

Экран: справочник страны, Греция, Jetpack Compose.

**Статус: реализовано.** До изменения приложения владельцу показаны [макеты](mockups/olive/states.png)
и SVG: [ветвь](mockups/olive/olive-branch.svg), [олива](mockups/olive/olive-fruit.svg).
В приложении используется ветвь. Макеты показывают открытую и закрытую карточку в обеих темах.

## Векторный бейдж

- Заменить системный эмодзи 🫒 плоской минималистичной векторной иконкой оливы / оливковой ветви.
- Размер иконки: 16–18 dp, приглушённый оливковый цвет `#8FA86A`.
- Обеспечить одинаковое отображение на разных версиях Android и соответствие дизайн-системе.
- Иконку или связку «Греция + иконка» поместить в компактную кликабельную капсулу `CircleShape`.
- Фон капсулы: `white.copy(alpha = 0.06f)` в тёмной теме,
  `black.copy(alpha = 0.05f)` в светлой. Бейдж должен считываться как интерактивный элемент.

## Нажатие и отклик

- Убрать крупный необрезанный ripple у иконки и кнопки «Скрыть»: он выходит за границы строки
  и наезжает на заголовок «Евро».
- Обрезать область по форме капсулы через `Modifier.clip(CircleShape)` либо отключить стандартную
  индикацию (`indication = null`), заменив её плавной сменой фона через `animateColorAsState`.
- Повторный тап по иконке закрывает карточку: бейдж работает как переключатель.
- Пока карточка открыта, иконка повёрнута от `0f` до `-14f` по `rotationZ`;
  переход — `spring(dampingRatio = Spring.DampingRatioMediumBouncy)`.

## Оливковый листопад

- Удалить нынешние полупрозрачные синие овалы в правом верхнем углу.
- При открытии карточки запускать 14–18 листьев по всему экрану через прозрачный `Canvas`
  поверх корневого `Box`. Оверлей не должен блокировать нажатия и прокрутку.
- Листья узкие, ланцетовидные, с заострёнными концами, не круглые овалы.
- Палитра: оливковые `#8FA86A`, `#6E854E` и серебристо-шалфейные `#B2BEB0`, `#9AA898`.
  Начальная прозрачность: `alpha = 0.7f–0.85f`, чтобы эффект не мешал чтению текста.
- Старт от верхней границы с разбросом задержек 0–350 мс.
- Плавное падение вниз за 1500–1900 мс, горизонтальное синусоидальное покачивание на лёгком ветру.
- Добавить вращение `rotationZ` и имитацию переворота плавным изменением ширины `scaleX`.
- В нижней трети экрана мягко растворять листья до `alpha = 0f`.

## Синхронное раскрытие и закрытие

Устранить пустой провал перед появлением карточки и задержку схлопывания после её исчезновения.
Согласованный вариант переходов:

```kotlin
AnimatedVisibility(
    visible = isOliveTipVisible,
    enter = expandVertically(
        animationSpec = tween(240, easing = FastOutSlowInEasing),
        expandFrom = Alignment.Top
    ) + fadeIn(
        animationSpec = tween(200, delayMillis = 40)
    ),
    exit = shrinkVertically(
        animationSpec = tween(220, easing = FastOutSlowInEasing),
        shrinkTowards = Alignment.Top
    ) + fadeOut(
        animationSpec = tween(150)
    )
)
```

При реализации соблюдать существующие правила `AppTheme`, доступности и `LocalReduceMotion`.
Перечисленные цвета оформить в теме. Реализация включена в 1.43.0 по запросу владельца «делать весь список».
