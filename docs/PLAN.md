# План работ

Источник требований — `docs/SPEC.md`. Решения по ходу — `docs/DECISIONS.md`.

## Этап 1. Каркас
- Gradle 9.8 (wrapper), AGP 9.4 со встроенным Kotlin, Kotlin 2.4 + Compose Compiler plugin, `libs.versions.toml`.
- Один модуль `:app`, пустой `MainActivity` на Compose, ресурсы, манифест (портрет, CAMERA).
- Ключ `keystore/app.keystore` для debug и release.
- CI `.github/workflows/android.yml`: тесты, lint, debug + release APK, релиз по тегу `v*`.
- `CLAUDE.md`, `docs/SPEC.md`, `docs/PLAN.md`, `docs/DECISIONS.md`.

## Этап 2. Domain (чистый Kotlin, без android.*)
- `Card`, `Receipt`, `CardRate`, `RateMath` (cardPerRub, cardPerAed, rubPerAed, выгода в %).
- `Numbers`: разбор ввода, форматирование ru-RU (деньги, курсы, шпаргалка, курс перевода «в удобную сторону»), даты по-русски.
- `Converter`: AED ⇄ ₽ ⇄ валюта карты, сравнение карт.
- `Calculator`: выражение «22 + 15,5 + 8», ввод с клавиатуры, «=».
- `price/PriceParser`: модель OCR (строки/слова с рамками), склейка частей, фильтры, скоринг, «старая цена».
- `price/PriceTracker`: сопоставление между кадрами, EMA, 2 из 4, удержание 400 мс, ≤ 6 меток.
- Unit-тесты на все контрольные значения из SPEC.

## Этап 3. Главный экран
- Тема: цвета SPEC (светлая/тёмная), шрифты Unbounded / Golos Text / JetBrains Mono, tnum.
- Мини-карты (1,586:1, градиенты, водяные знаки, бейдж выгоды, анимация выбора).
- Результат, плашка курса, сравнение с полосками, «линия метро», чипы, клавиатура, кнопка «Ценник».
- Шпаргалка.
- `MainViewModel` + `StateFlow`.

## Этап 4. Шторка «Курс» + DataStore
- Ручной курс, бумажный чек (зубчатый край, отточия, моноширинные цифры), итог на лету, две кнопки.
- `SettingsRepository` на Preferences DataStore: карта, курсы/чеки/источник/дата, выражение и активная строка.

## Этап 5. AR-камера
- Разрешение CAMERA (объяснение, «Открыть настройки»).
- `LifecycleCameraController` + `PreviewView` + `MlKitAnalyzer` (VIEW_REFERENCED), bundled Text Recognition v2.
- Конвейер на фоновом executor: OCR → `PriceParser` → `PriceTracker` → раскладка меток.
- Canvas-оверлей без аллокаций в draw; шторка метки; полоска «отмечено»; фонарик, пауза, зум, фокус, ₸/¥.

## Этап 6. Полировка и релиз
- Тёмная тема, адаптивная иконка, TalkBack-подписи, «уменьшить анимацию».
- README по-русски, тег `v0.1.0` → GitHub Release с APK.

  в обмене наличных, «Списали» для валютной карты и «Отдали» для наличных в знакомстве.
  Соблюдать допустимые валюты конкретного поля и действующие ограничения выбора итоговой валюты
  и валюты расчёта UnionPay. Проверить выбор JPY вне быстрого списка, возврат без выбора и видимость
  кнопки при прокрутке меню.
- [x] **Анимация сохранения карты.** После подтверждения выполнять сохранение ровно один раз,
  в том числе при повторном «Назад» или смене режима анимаций. Согласовать показ галочки с началом
  закрытия редактора, чтобы убрать отдельное ожидание перед переходом.
- [x] **Возврат карты на главный экран.** Перед обратным перелётом брать актуальные координаты
  мини-карты. Если строка скрыта или координаты нельзя получить, закрывать редактор коротким
  затуханием. Проверить открытие и закрытие на мерцание и смену размера окна при складывании Fold.
- [x] **Галочка выбранной карты.** Зарезервировать место под галочку и плавно менять её прозрачность
  и масштаб вместе с цветом и подъёмом строки. Проверить длинные суммы и названия на узком экране.
- [x] **Длительность каскада и запрос высокой частоты.** Завершать каскад настроек и редактора
  вместе с последней анимированной группой. Проверить на Samsung, когда снимается запрос высокой
  частоты после анимации и жеста, и отдельно измерить фактическую частоту панели.
- [x] **Режим «Без анимаций».** При отключении анимаций или включении энергосбережения доводить
  начатые переходы до конечного состояния. Проверить состояние клавиш, каскада и закрытие редактора.
- [x] **Завершение знакомства.** Во время секундного перехода передавать нажатия и TalkBack только
  активному экрану. Проверить быстрый повторный тап, «Назад» и завершение с клавиатурой. Сохранить
  текущие тайминги перехода.
- [x] **Клавиша `000` для крупных номиналов — вариант 1.** Для активных валют с крупными номиналами,
  например VND, IDR и IRR, использовать нижний ряд `0 · 000 · ,`. Клавиша `000` дописывает три нуля
  к текущей целой части (`125` → `125 000`). Раскладка зависит от активной валюты, а не от текущего
  курса. Проверить начало нового слагаемого, попытку дописать `000` после запятой и выход за лимит
  12 цифр. При недопустимом вводе сохранить число целиком и показывать понятную подсказку.
- [x] **Лимит позиций в калькуляторе.** Когда достигнут лимит в 30 слагаемых, дать явную обратную
  связь при попытке добавить ещё одно. Не дописывать цифру к последней позиции после отклонённого
  оператора. Проверить 30 единиц и попытку добавить `+ 2`: ошибочный итог `41` недопустим.
- [x] **Сохранение суммы при смене страны без курса.** Если пересчёт в новую валюту пока невозможен,
  показать, что курс недоступен, и сохранить исходную сумму и выражение для возврата. Проверить
  переход с `250 AED` в валюту без курса и обратно, в том числе офлайн.
- [x] **Точность при переключении валюты ввода.** Использовать исходную сумму и полную точность для
  пересчёта. Округлять только при показе. Переключение туда и обратно без редактирования должно
  вернуть исходный ввод. Проверить `1 VND → 0,0032 RUB → 1 VND`.
- [x] **Точность при нажатии `=`.** Сворачивать выражение без потери значения для дальнейших
  вычислений. Проверить `1,25 × 0,13`: результат `0,1625` сохраняется с полной точностью, даже если
  на экране показывается округлённая сумма.
- [x] **Ввод после перезапуска.** Сохранять признак завершённого результата при записи состояния.
  После `7 + 5 =` и перезапуска клавиша `3` начинает новое число `3`, а незавершённый ввод остаётся
  редактируемым. Проверить восстановление сохранений предыдущих версий.
- [x] **Дробная часть по валюте и подсказка о лимите.** Поддержать три дробных знака для BHD, JOD,
  KWD, LYD, OMR и TND при наборе и переносе цены из фото. Проверить сохранение `1,234 KWD` в расчёте
  и после `=`. Для AZN оставить два знака и при попытке ввести третий объяснить лимит. Проверить
  такую же обратную связь на пределе 12 цифр целой части.
