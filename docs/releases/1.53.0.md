# 1.53.0

- Палитра из семи готовых цветов и свой RGB/HEX-цвет для каждой карты с предпросмотром.
- Четыре значка: Классика, Золото, Изумруд и Платина.
- Персонализация в PRO: AMOLED, цвета карт и значок приложения.
- «Цвета из обоев» доступны бесплатно в настройках Android 12+.
- Добавление виджета и плитки камеры из PRO; прежние системные ярлыки убраны из предложения.
- Банковских шаблонов нет. Суммы, курсы и чеки сохраняются при смене оформления.

Этот APK предназначен для самостоятельной проверки на телефоне: выпуск без эмулятора и визуального gate (`phone-check`).
