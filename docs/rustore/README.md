# Выгрузка в RuStore

Всё для карточки приложения в консоли RuStore (https://console.rustore.ru). Тексты можно копировать
как есть: длины проверены по ограничениям консоли.

## Файл сборки

- **APK** — `dirhamrub-vX.Y.Z.apk` из GitHub Release (workflow `android.yml`, ручной запуск с
  `release=vX.Y.Z`). Подписан ключом из секретов репозитория (новый с 1.18.0, `ru.kurspocheku`):
  RuStore принимает обновления только с той же подписью — ключ больше не менять и хранить копию
  файла ключа и паролей вне GitHub.
- `versionCode` — номер запуска CI, всегда растёт; `versionName` — из `app/build.gradle.kts`.
- Только `arm64-v8a`: старые 32-битные телефоны RuStore не покажет — это ожидаемо.
- Сервисы Google не нужны: ML Kit встроен в APK, приложение работает на телефонах без Google
  (Huawei, Honor и т. п.).

### Полное описание

```
Сколько на самом деле стоит покупка за границей в рублях? Банк списывает не по курсу ЦБ, а по своему — и у каждой карты он свой. «Курс по чеку» считает реальный курс по вашим же чекам и показывает, какой картой платить выгоднее.

КАК ЭТО РАБОТАЕТ
• Добавьте карту или наличные и один чек: сколько стоила покупка и сколько списали. Из этого приложение узнаёт курс именно вашей карты — со всеми наценками банка.
• Вводите цену в местной валюте — сразу видно сумму в рублях по каждой карте, лучшая отмечена.
• Сравнение с курсом ЦБ РФ: на сколько процентов банк дороже официального курса.
• Нет чека — считаем по курсу ЦБ и честно помечаем сумму знаком «≈».

КАМЕРА ПОВЕРХ ЦЕННИКОВ
Наведите камеру на меню или витрину — рубли появятся прямо на ценниках. Распознавание работает на телефоне, без интернета.

ЛЮБЫЕ КАРТЫ И ВАЛЮТЫ
• Около 150 валют и 240 стран: дирхамы, лиры, баты, тенге, юани, донги, драмы и другие.
• Рублёвые карты, карты в валюте, UnionPay, наличные из обменника и банкомата.
• Итог можно считать не только в рублях.
• Чек можно заполнить со скриншота банковского приложения.

УДОБНО В ПОЕЗДКЕ
• Шпаргалка с ходовыми суммами — пригодится на рынке.
• Подсказка при смене страны: «Вы в Армении — считать в драмах?».
• Плитка «Ценник» в шторке — камера одним касанием.
• Тёмная и светлая тема.

ЧЕСТНО С ДАННЫМИ
Без регистрации, рекламы и аналитики. Карты и чеки хранятся только на телефоне. Интернет нужен лишь для курсов ЦБ РФ и UnionPay, всё остальное работает офлайн.
```

## Скриншоты

RuStore просит от 3 до 10 вертикальных скриншотов 9:16. CI снимает их на каждый push в 1080 × 1920
(экраны свёрстаны под эту высоту, а не обрезаны) — файлы `store-*.png` в пререлизе **screens**
(https://github.com/KosHG28/monyexhange/releases/tag/screens), номер в имени — порядок в карточке:

1. `store-1-main.png` — главный экран: суммы по картам, лучшая карта.
2. Камера поверх ценников — **снимите на телефоне** (в меню или магазине; системный скриншот, затем
   обрежьте до 9:16): камера эмулятора видит только виртуальную комнату.
3. `store-2-why.png` — зачем: курс банка ≠ курс ЦБ.
4. `store-3-how.png` — как считаем.
5. `store-4-editor.png` — карта и чек.
6. `store-5-cheat.png` — шпаргалка.
7. `store-6-main-light.png` — светлая тема.
8. `store-7-settings.png` — курсы ЦБ и UnionPay, настройки.

## Разрешения (ответы модерации)

| Разрешение | Зачем |
|---|---|
| `CAMERA` | Режим «суммы поверх ценников»: распознавание цен на телефоне, кадры не сохраняются. Необязательное — без него работает всё, кроме камеры. |
| `INTERNET` | Только загрузка курсов ЦБ РФ (cbr.ru и зеркало cbr-xml-daily.ru) и UnionPay. |
| `ACCESS_NETWORK_STATE` | Настройка «Только по Wi-Fi»: узнать, платная ли сейчас сеть, чтобы в роуминге не скачивать курсы самим. Ничего не передаёт. |
